# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or include a real chat
export in a report. Use GitHub's private vulnerability reporting option in the
repository's **Security** tab and provide a minimal synthetic reproduction when
possible.

Reports involving unintended extraction, path traversal, temporary-file
exposure, archive bombs, or disclosure of chat data are especially important.
You should receive an initial response within seven days.

## Supported versions

Until stable releases are published, security fixes are made on the `main`
branch.
