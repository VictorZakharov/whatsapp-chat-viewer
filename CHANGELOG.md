# Changelog

All notable changes to WhatsApp Chat Viewer are documented here.

## [1.0.0] - 2026-08-30

### Added

- Direct, read-only viewing of one or more WhatsApp chat export ZIPs without
  unpacking the archive.
- Virtualized chat navigation, message search, persistent date display, and
  jump-to-date-and-time.
- Lazy image and video loading with a unified media viewer, chronological
  filmstrip, expandable gallery, rotation, fullscreen playback, and keyboard
  controls.
- Self-contained Windows x64 release packaging with a SHA-256 checksum.
- MIT licensing, third-party notices, CI, Dependabot, private vulnerability
  reporting, secret scanning, and protected pull-request-only development.
